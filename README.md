# 📊 Classificação PSS 02/2025 – Contagem/MG

## 🎯 Problema

A consulta da classificação do PSS 02/2025 da Prefeitura de Contagem apresentava diversas dificuldades:

* Informações distribuídas em arquivos **ZIP**
* Dados fragmentados em **vários PDFs**
* Ausência de busca por nome
* Baixa usabilidade em dispositivos móveis

Esse cenário tornava a experiência do candidato **lenta, confusa e pouco acessível**.

---

## 💡 Solução

Foi desenvolvido um sistema completo para:

* 📥 Extrair dados dos PDFs oficiais
* 🔄 Estruturar e consolidar as informações
* 🔎 Permitir busca por nome
* 🎯 Filtrar por cargo
* 📱 Disponibilizar interface simples e responsiva

🔗 Acesse o projeto:
https://thiago-dumont.github.io/Pss022025/

---

## ⚙️ Tecnologias utilizadas

### 🔹 Backend / Processamento de dados

* Python
* Pandas
* Extração e tratamento de dados de PDFs

### 🔹 Frontend

* HTML
* CSS
* JavaScript
* Biblioteca XLSX (leitura de planilhas no navegador)

---

## 🧠 Pipeline de Dados

1. Extração dos dados dos PDFs oficiais
2. Tratamento e limpeza das informações
3. Consolidação em arquivos estruturados (.xlsx)
4. Disponibilização para consumo via interface web

---

## 📊 Funcionalidades

* 🔍 Busca por nome
* 🎓 Filtro por cargo
* 📈 Exibição de classificação
* 🧾 Indicação de cotas (negro / PCD)
* ⚡ Interface leve e rápida
* 📱 Compatível com celular

---

## 🚀 Impacto
